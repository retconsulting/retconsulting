Markdown, set like a book.

“Emdee” is how you say .md out loud. A native reader and editor for Mac, iPad and iPhone.

Coming soon to the App Store. Free, with no purchases or subscriptions. The interface is in French.

A page made for reading

Open any .md file and read it as a set page: real typography, a table of contents, search, footnotes and sidenotes. Tables, tasks, mathematics and diagrams come out clean.

The source or the page, your choice

Press Modifier, or Command-E, and two panes open: the Markdown on one side, the rendered page on the other. Type in either. Each updates the other, and your files stay plain .md.

The document, as a book

Book mode turns a Markdown file into a paginated book, full screen: a cover, a table of contents, chapter openings, running headers and page numbers. On Mac, export these pages as a PDF book.
