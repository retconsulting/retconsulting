Visite du site

Ce site ne dépose aucun cookie et n’utilise aucun outil de mesure d’audience ni traceur publicitaire. Les polices et les images se chargent uniquement depuis ce site. GitHub, Inc. héberge les pages via GitHub Pages. Lorsque vous les consultez, GitHub enregistre votre adresse de protocole Internet (IP) à des fins de sécurité. RET Consulting se fonde sur son intérêt légitime à disposer d’un site sûr et disponible. GitHub est établi aux États-Unis. Pour ces transferts, GitHub s’appuie sur le cadre de protection des données UE–États-Unis (Data Privacy Framework) et sur des clauses contractuelles types. Documentation de GitHub Pages.

Formulaire de contact et e-mail

Le formulaire de contact ouvre un brouillon dans votre messagerie. Le formulaire n’envoie rien lui-même. Vous décidez d’envoyer l’e-mail.

Si vous envoyez un e-mail, RET Consulting SRL reçoit votre adresse, votre message et les éventuelles pièces jointes. RET Consulting les utilise pour vous répondre et traiter votre demande. RET Consulting SRL est responsable du traitement de ces échanges. Ce traitement repose sur son intérêt légitime à répondre aux demandes. Si vous demandez un devis ou un contrat, il repose aussi sur les mesures précontractuelles que vous demandez.

Google Workspace, fourni par Google Cloud EMEA Limited (Irlande), transmet et conserve les e-mails pour RET Consulting. Google peut traiter des données hors de l’Espace économique européen, notamment aux États-Unis. Pour ces transferts, Google s’appuie sur le cadre de protection des données UE–États-Unis et sur des clauses contractuelles types.

RET Consulting conserve la correspondance jusqu’à trois ans après le dernier échange. Si l’échange aboutit à un contrat, les durées légales de conservation des documents comptables et fiscaux s’appliquent. Écrire à RET Consulting est facultatif. Sans votre e-mail, RET Consulting ne peut pas vous répondre. RET Consulting ne prend aucune décision automatisée et ne fait aucun profilage avec vos données.

Vos droits lorsque RET Consulting reçoit des données personnelles

Vous pouvez demander à RET Consulting SRL l’accès à vos données personnelles, par exemple une copie de votre message. Vous pouvez aussi demander leur correction ou leur effacement. Écrivez à retbaz@retconsulting.be.

Le règlement général sur la protection des données (RGPD) vous permet aussi, dans certains cas, de demander la limitation de l’utilisation de vos données. Vous pouvez vous opposer, pour des raisons liées à votre situation, à un traitement fondé sur l’intérêt légitime. La portabilité concerne les données que vous avez fournies lorsque leur traitement automatisé repose sur votre consentement ou sur un contrat. Vous pouvez introduire une réclamation auprès d’une autorité de contrôle, notamment l’Autorité de protection des données belge.
